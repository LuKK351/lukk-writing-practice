# 练习方法

[回到开始练习](01%20开始练习.md) · [去选题库找材料](02%20选题库.md)

看哪一项像你现在的困难，把那句话告诉 AI 就可以。拿不准时，先交给 AI 看整篇，再一起选。

| 我现在想解决什么 | 可以怎样练 |
| --- | --- |
| 事情我知道，别人读完却不明白怎么发生的 | **把一件事写清楚**：补上必要的前情或关系，让人能跟着经过读下来。 |
| 我写了“难过”“紧绷”，却说不清那是什么感觉 | **让感受落在真实细节上**：用确实记得的行为、场景或念头，让感受有具体所指。 |
| 想说的太多，不知道哪些该留下 | **确定中心与材料取舍**：围绕这篇最想说的事，亲手做一次删、留或详略调整。 |
| 句子读着费劲，或段落接起来有点绕 | **安排理解的顺序**：试一次拆句、合句或调序，比较读者能否更顺地理解。 |
| 自己很熟悉，却很难向不了解的人解释 | **向不了解的人解释**：补一个必要背景、例子或区分，让对方听懂你具体在说什么。 |
| 我有一个判断，但不知道理由够不够 | **让判断有根据**：检查理由是否支持结论，或试着回应一条不同意见。 |
| AI 给了修改建议，我不知道该不该接受 | **做一次有理由的修改**：指出原文的问题，自己改一处，或说明为什么保留。 |
| 两种写法都说得通，我想知道怎么选 | **比较写法与选择**：对照具体文字，说清各自的效果和代价，再选适合自己的。 |

可以只练一个动作，也可以带同一篇短文从起稿练到完成。八种方法按需要选，不用按顺序学完。

这些练法以刘军强《写作是门手艺（修订版）》为基础，转化为日常短文练习。开始带练时，AI 会解释用到的方法、展示差别，再请你尝试。
