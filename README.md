# LuKK 写作练习

和 AI 一起练习几百至两千字的日常短文：把自己想说的事写清楚，也知道每次修改为什么值得做。

以刘军强《写作是门手艺（修订版）》为方法基础，将适合普通写作者的工具转成小任务、例证与检验标准。你负责写作和取舍，AI 负责解释方法、指出具体问题、检验修改并整理记录。不评分，不要求日更。

## 第一次使用

需要一个能读取本地 Skill、读写文件并运行 Python 3 的 AI 工具，以及一个已有的 Obsidian 库。基本练习不需要 Obsidian 插件或额外模型 API。

以 Codex 为例，把本仓库放在 `~/.codex/skills/lukk-writing-practice`。使用自定义 `CODEX_HOME` 时放在其 `skills` 目录下。可以下载 ZIP 后解压并改为该文件夹名，也可以克隆：

```bash
git clone https://github.com/LuKK351/lukk-writing-practice.git ~/.codex/skills/lukk-writing-practice
```

已有同名目录时先核对，不另复制一套或直接覆盖。仓库为私有时，下载或克隆需要相应访问权限。其他支持本地 Skill 的 AI 工具按各自安装方式放置完整目录；目前的文件工具流程主要在 Codex 中验证。

安装后，在下一轮对话中说：

> 用 lukk-writing-practice 带我练一篇短文。我想写……，从空白开始。把练习存到我的 Obsidian 库里的“写作练习”文件夹。

首次使用时，AI 会请你指定或确认库和练习目录，检查能否读写，再建立文件。已有目录绑定时直接恢复，不需要每次重新设置。没有本地文件能力的 AI 仍可讨论方法，但不能替你保存稿件或恢复本地进度。

## 可以怎样开始

**已经有一段文字**

> 用 lukk-writing-practice 看看下面这段笔记。先给我完整诊断和训练地图，再选一个值得练的地方。

**想写，但没有选题**

> 从我已授权的 Flomo 里，看看最近一周的记录，找 3 个适合写短文的小选题。说明可以写什么，并附原记录出处。

也可以指定 Get 笔记、Obsidian 文件夹、其他已接通的资料源，以及不同的时间范围或主题。前提是当前 AI 已能访问对应来源；本 Skill 不负责替笔记服务接通账号。AI 先给候选，你选中后再开练，未选题目按你的要求存进选题库。

**继续上一篇**

> 用 lukk-writing-practice 继续上次那篇。我已经改好了，请读取最新稿再带我往下练。

如果有多篇正在进行，说明题目或练习编号即可。AI 会回读文件与记录，不依赖上一窗口的聊天记忆。

## 一篇会怎样练

1. **先看全文地图。** 初稿完成后，AI 说明已经成立的地方和已识别的重要问题，区分必须处理与可选优化。没有完整稿时先帮助起稿，不编造诊断。
2. **一次练一个主要动作。** 解释用到的方法、展示差别，你亲手尝试，再按约定标准对照检验。
3. **改完回到全文。** 更新地图，确认哪些问题解决了、哪些顺带消失、哪些保留，避免一直陷在一句话里。
4. **最后完整检查字词句。** 通读全文，一次列齐本遍发现的必要与可选事项；不把个人语气自动当成病句。
5. **你决定结束，留下实际收获。** 记录采用稿、本人做了什么、前后收益与取舍，以及哪些能力尚未独立验证。

版本按修改阶段保留，不是每改一句就新建一版。AI 会主动说明何时值得建新版，你也可以明确要求沿用当前版或另存。

## 文件存在哪里

安装 Skill 和存放练习是两个位置。Skill 是通用工具，Obsidian 文件夹保存你的个人作品：

```text
你指定的练习目录/
├── 00 我的练习/
│   └── W001 文章题目/
│       ├── R01 练习记录.md
│       ├── V01 从空白开始写初稿.md
│       └── V02 本轮主要修改目标.md
├── 01 开始练习.md
├── 02 选题库.md
└── 03 练习方法.md
```

第一次从“01 开始练习”进入。“00 我的练习”存作品；文章正文与训练记录分开，版本数量由实际修改决定。目录中另有工具维护的隐藏状态和恢复快照 `.writing-practice`，日常不用操作，备份或搬迁时一并保留。

本机目录绑定保存在用户配置目录，不写进 Skill。分享仓库或 Skill 时不会包含你的文章、笔记、练习状态或个人配置。不要把整个 Obsidian 练习目录放进此仓库。

## 原书依据与迭代方式

方法文件标明书中工具的位置，区分书例摘要、短引、他人原文与系统原创示例。短文任务、AI 检验和停止条件是面向日常写作的改编；一般语法判断也会如实说明，不能只挂一个章节号就宣布修改有效。仓库不包含完整原书，运行不依赖 EPUB。

AI 的文本判断与模拟阅读不等于真人读者反馈，一次有提示的改写也不代表独立掌握。你可以纠正误读、拒绝可选建议或保留原文。

自用与分享维护同一套 Skill。AI 入口见 [SKILL.md](SKILL.md)，节点安排见[流程](references/流程.md)，维护者可查[工具使用](references/工具使用.md)。个人练习与开发复盘保存在仓库之外；发布时使用仓库内容或 GitHub 源码 ZIP，不把 `.git` 历史和本地缓存作为 Skill 资源打包。
