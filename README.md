# LuKK 写作练习

**这是一个供你自己练习写作的 Skill。** 你可以用 Codex、Claude Code 或其他支持 Skill 的 AI Agent，练习几百至两千字的日常短文，逐步提升自己的写作与判断力。

**AI 不给你具体的评分，也不帮你直接写作。** 它会解释方法、展示例子、指出问题，再检验你的修改。文章由你亲手写，改不改、怎么改也由你决定。

方法来自刘军强《写作是门手艺（修订版）》，经过改编，用于写自己的经历、观察、感受或想法。你不需要有系统写作训练的基础，也不必写论文或小说。

## 第一次使用

### 1. 让 AI 安装这个 Skill

打开你正在使用的 AI Agent，把下面这段话发给它：

> 帮我安装这个写作练习 Skill：https://github.com/LuKK351/lukk-writing-practice 。安装后检查一下本地环境是否能正常使用。

AI 会按当前工具的安装方式处理，并检查环境。安装的是整套 Skill，你不用逐个复制规则文件。不同 Agent 的安装方式不同；目前完整的本地文件流程主要在 Codex 中验证。安装后，按工具提示在下一轮对话或新窗口调用。

### 2. 告诉 AI，练习要存到哪里

在 Obsidian 中选一个你平时使用的库。这里的“库”就是存放笔记的文件夹，把它的路径告诉 AI：

> 我的 Obsidian 库在「这里填文件夹路径」。请在里面建一个“写作练习”文件夹，用来保存我的练习。

AI 会检查这个目录并建立练习入口。你不用自己建模板、安排版本或维护后台记录。只需首次确认保存位置，以后可以继续使用；如果还没有 Obsidian 库，先在 Obsidian 中创建或打开一个文件夹。

### 3. 开始第一篇

告诉 AI 你想写什么即可。例如：

> 用 lukk-writing-practice 带我练一篇短文。我想写“最近换了表盘，发现自己其实只看时间”。请先和我明确这次要写什么，再建一个空白初稿，我自己写。

AI 建好练习后会给出文件位置。你在 Obsidian 里打开初稿、写下文字并保存，然后回到 AI 对话说：

> 我写好了，请读取最新稿，先告诉我整篇有哪些值得练的地方，再带我一步一步改。

没有想好题目，或已经写过一段文字，可以从下面选择对应的方式开始。

## 可以怎样开始

### 有想法，还没动笔

把想写的那件事告诉 AI，不必先想好标题和结尾。它会帮你缩小范围、明确本次写作目标，再建立空白稿。

> 用 lukk-writing-practice 带我从头练。我想写……，但还没想好从哪里开始。先和我聊清楚，再让我自己起稿。

### 已经有笔记或草稿

贴出文字或给出本地文件位置，说明要把它当原稿继续练。AI 会保留原文；有完整稿就先给全文诊断，再选训练入口，只有片段则先帮你判断还需要写什么。

> 用 lukk-writing-practice 带我练。这是我以前写的一段文字，请把它作为原稿保留，先帮我看看整篇，再告诉我可以从哪里开始练：……

### 没有题目，让 AI 从自己的笔记里找

指定一个已授权、AI 能读取的笔记来源，比如 Flomo、Get 笔记或 Obsidian 文件夹，再说明想看哪段时间或哪个主题。

> 用 lukk-writing-practice，从我已授权的 Flomo 里看看最近一周的记录，找 3 个适合练短文的小选题。告诉我各自可以写什么、材料来自哪条记录，先让我选。

你选中后，可以让 AI 建空白稿、由自己重新写；也可以明确要求从已有原文继续。剩下的候选想留到以后再写，就说“把其他几个存进选题库”。如果 AI 还不能访问笔记来源，可以先直接贴一段笔记开始，不必为了开练先接通所有服务。

### 已经在练，继续改上一稿

在 Obsidian 中写完并保存，回到 AI 对话说：

> 用 lukk-writing-practice 继续《文章题目》这篇。我已经改好了，请读最新稿，对照我们这次的目标看改动有什么效果，再看下一步。

换了窗口也可以这样说。AI 会回读练习记录、全文地图和当前稿，确认还有哪些事项；有多篇正在进行时，说明题目或练习编号即可。

## 环境要求：让 AI 帮你检查

你准备好 **AI Agent 和 Obsidian**，其余本地检查交给 AI：

| 需要什么 | 用来做什么 | 不满足时怎么办 |
| --- | --- | --- |
| 支持本地 Skill 的 AI Agent，例如 Codex、Claude Code | 读取方法和流程，与你对话带练 | 使用具备这类能力的工具；普通聊天窗口不能完成这里的本地保存流程 |
| 一个 Obsidian 库，并允许 AI 访问练习文件夹 | 让你写正文、查看训练地图与记录 | 在 Obsidian 中创建或打开库，再把路径告诉 AI |
| Python 3 | 运行 Skill 自带的小工具：建立练习、保存稿件快照、维护版本和记录 | 首次使用时由 AI 检查；没有可用环境时，先说明当前系统的安装方式，再按你的授权协助安装并验证 |

**你不需要写 Python，也不需要自己运行这些命令。** 首次建立练习，以及后续保存版本、更新记录时，AI 会调用这些工具。它们直接处理笔记文件，不通过 Obsidian API 操作软件，所以不需要为此安装 Obsidian 插件。

本 Skill 没有额外的模型 API 配置要求；你仍使用所选 AI Agent 自身的模型服务。Flomo、Get 笔记等外部来源的访问只在你要从那里找选题时才需要。环境未就绪时可以先讨论想法，AI 不应声称已经保存了练习。

## 一篇会怎样练

1. **先看全文地图。** 初稿完成后，AI 说明已经成立的地方和已识别的重要问题，区分必须处理与可选优化。没有完整稿时先帮助起稿，不编造诊断。
2. **一次练一个主要动作。** 解释用到的方法、展示差别，你亲手尝试，再按约定标准对照检验。
3. **改完回到全文。** 更新地图，确认哪些问题解决了、哪些顺带消失、哪些保留，避免一直陷在一句话里。
4. **最后完整检查字词句。** 通读全文，一次列齐本遍发现的必要与可选事项；不把个人语气自动当成病句。
5. **你决定结束，留下实际收获。** 记录采用稿、本人做了什么、前后收益与取舍，以及哪些能力尚未独立验证。

版本按修改阶段保留，不是每改一句就新建一版。AI 会主动说明何时值得建新版，你也可以明确要求沿用当前版或另存。

## 文件存在哪里

安装 Skill 和存放练习是两个位置。Skill 是通用工具，Obsidian 文件夹保存你的个人作品：

```text
你指定的练习目录/
├── 00 我的练习/
│   └── W001 文章题目/
│       ├── R01 练习记录.md
│       ├── V01 从空白开始写初稿.md
│       └── V02 本轮主要修改目标.md
├── 01 开始练习.md
├── 02 选题库.md
└── 03 练习方法.md
```

第一次从“01 开始练习”进入。“00 我的练习”存作品；文章正文与训练记录分开，版本数量由实际修改决定。目录中另有工具维护的隐藏状态和恢复快照 `.writing-practice`，日常不用操作，备份或搬迁时一并保留。

本机目录绑定保存在用户配置目录，不写进 Skill。分享仓库或 Skill 时不会包含你的文章、笔记、练习状态或个人配置。不要把整个 Obsidian 练习目录放进此仓库。

## 原书依据与迭代方式

方法文件标明书中工具的位置，区分书例摘要、短引、他人原文与系统原创示例。短文任务、AI 检验和停止条件是面向日常写作的改编；一般语法判断也会如实说明，不能只挂一个章节号就宣布修改有效。仓库不包含完整原书，运行不依赖 EPUB。

AI 的文本判断与模拟阅读不等于真人读者反馈，一次有提示的改写也不代表独立掌握。你可以纠正误读、拒绝可选建议或保留原文。

自用与分享维护同一套 Skill。AI 入口见 [SKILL.md](SKILL.md)，节点安排见[流程](references/流程.md)，维护者可查[工具使用](references/工具使用.md)。个人练习与开发复盘保存在仓库之外；发布时使用仓库内容或 GitHub 源码 ZIP，不把 `.git` 历史和本地缓存作为 Skill 资源打包。
